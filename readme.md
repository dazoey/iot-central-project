# IoT Central Management System

Sistem terpusat berbasis PWA untuk monitoring dan kontrol perangkat IoT (LoRaWAN & MQTT native).

## Tech Stack
- **Database:** PostgreSQL + TimescaleDB
- **Backend Core:** Node.js (JavaScript)
- **Frontend:** React + Vite (PWA)
- **Network / Protocol Service:** C++
- **Machine Learning Service:** Python
- **LoRaWAN Server:** ChirpStack

## Cara Menjalankan Infrastruktur Lokal
1. Pastikan Docker Desktop sudah berjalan.
2. Jalankan perintah: `docker-compose up -d`
